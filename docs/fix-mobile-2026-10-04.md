# 手机界面与字母序（2026-10-04）

安卓壳通过既有 `__androidTTS` 桥或 Android WebView 标记识别：隐藏 APK 下载入口。手机、触屏与安卓壳隐藏电脑操作说明、一次性键盘推荐和快捷键字符；桌面快捷键路径不变。

保留存档 `kbMode`：true 是 QWERTY，false 改为 A–Z 字母序网格。只排序视觉实例索引，不重排字母状态；重复字母、已用键、半词输入与刷新继续保持。旧存档键及未知字段不变。

手机装备展开后名称在上、说明在下，均占满宽度；桌面两列保持。字母盘旁常驻「听读音 / 提示共用：剩余 N 次」，听读音同步更新并保存次数。长按两遍只扣一次，松手不再二次扣费；暂停时不能消耗。

先写失败的字母序/电脑推荐单测及真实浏览器验收，再实现。覆盖安卓桥、手机与桌面、320/390/1024 宽度、图标归属、说明宽度、可点字母、切布局继续与共享额度；去掉 A–Z 排序的变异会使断言失败。冻结七张样式表与教材词不变。旧 APK 冷启动检查新版 version.json 并清理页面缓存，用户须完全退出后再打开才能可靠刷新；不删除存档。
