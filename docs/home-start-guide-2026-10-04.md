# 首页先开始，再调整范围

原首页先显示教材、单元和九名角色，第一次打开不容易看懂下一步。
这次保留全部选择控件和开局规则，只重排首页并提供一次性简短引导。

- 标题下直接显示“开始游戏”，滚动时保留在顶部，并避开顶部安全区。
- 按钮旁显示当前册、单元、真实词数和角色，选择变化立即同步。
- 教材、单元与角色选择放到下面。当前选择已可开局，不要求先做额外选择。
- 暂停远征的“继续远征”也在顶部操作区，继续仍恢复原来的冻结范围。
- 首次显示三步说明：点地图发亮节点、看中文拼英文、拼对出招。
  点“知道了”或开始游戏后保存 `homeTutorialSeen:true`，刷新、回主页不再自动显示。
  用户随时可点“怎么玩”重新查看，重看不清除已读记录。
- 引导在正常页面流中，不使用遮住开始按钮的弹窗。

新增组件 `src/ui/components/home-start.js` 只读显式 getter、重排 DOM，
保存通过 runtime 的既有 `saveDB/commit` 端口。`home-start.css` 仅作用于
`#s-title`，追加在 CSS 导入清单末尾。原始 259 词、七张冻结表、存档 key
和玩法判定均不变；旧档与未知字段保留。

## 手动重看时避开顶部按钮

最终生产构建复查发现：从页底点“怎么玩”时，`scrollIntoView(nearest)`
把教程顶部滚到视口顶部，常驻按钮盖住了标题和前两步。320px 实测教程
顶部约 0.5px，操作区底部 122px。首次进入的教程不受此问题影响。

在教程自身加 `scroll-margin-top:calc(180px + env(safe-area-inset-top,0px))`，
为含继续入口的顶部操作区留出滚动避让；不改变首次展示或已读记账。
新增 320×568、390×844（已暂停远征）、1024×768 真滚动测试，先 3 项失败，
修复后与开始入口回归一起 13/13 通过，退出码 0。
删除滚动避让的变异被 320px 标题无遮挡断言检出（退出码 1，1 项失败）。
版本更新为 `2026.10.04-home-start-guide-2`，完整门禁与公网验收仍须通过。
