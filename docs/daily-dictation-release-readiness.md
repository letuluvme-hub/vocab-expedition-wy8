发布准备 PR 最后合入该整合分支；整合结果须与本 PR 已验收的最终文件树逐字节一致。然后创建独立总整合 PR 指向 main，记录各阶段已合并 PR 与 tree SHA，待该最终树 CI 通过、确认 main 基线仍未移动后，一次合到 main，触发现有 Pages 工作流。这样正式网站一次收到完整改版。等待 exact 最终 main 提交的 Verify 和 Deploy 都成功，并执行完整公网验收，才记录上线时间和成功结论。不跳过 CI、不强推、不改 Pages 来源、不清存档。
