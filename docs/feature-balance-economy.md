# 商店与战利品平衡（2026-10-03）

此次调整让商店购买与战斗补给有明确边界，同时保留已经展开的旧卡承诺。角色被动、战斗内道具效果与金币倍率由本轮其他模块负责。

## 规则

| 项目 | 新规则 |
| --- | --- |
| 遗物购买 | 持有后不能重复买。同一按钮再次点击或刷新后恢复，均不扣钱、不添加重复遗物、不重跑初始化。 |
| 疗伤药 | 45 金币恢复最多 35 生命，满生命拒绝购买。 |
| 提示卷轴 | 每份 40 金币，下一场额外提示 +3，商店卷轴最多积累 6 次。若本次购买会超过 6 次，整份拒买。旧档已有超过 6 次的额度保留。 |
| 道具库存 | 每次购买仍给 3 件。`ITEMS.max` 是每场使用额度，不能拿它限制 `bag` 库存、商店上架或战利品。 |
| 回血战利品 | 普通战最多 12，精英最多 18；卡面写实际缺血量，不随敌人生命增长。首领战保持不出回血卡。 |
| 先知卡 | 保留学者之书原有概率与点金术保底逻辑，仍由原 `nextHint` 路径兑现。 |

商店实时与恢复路径共用疗伤药、卷轴、遗物及道具购买动作。恢复屏买完东西也立即显示新的金币数。战斗奖励仍只有一次领取机会，治疗写到 `B.myHp` 后由 `finishNode` 结转。

## 旧存档

不改变 `wy8a_rogue_v1` 或快照 schema。新增卡片仍存原有字符串 id 字段：

- 新道具卡为 `shop:item:<id>:<price>`；恢复按该卡已记录的价格购买 3 件。
- 旧 `shop:item:<id>` 从固定历史价格表恢复：吸血 60、怒火 65、寒冰 50、连锁 55、透视 45、扫除 40、贪婪 35、磐石 70。
- 带价格的遗物卡恢复按 id 内价格兑现，避免当前稀有度价格变化让旧卡丢失；无价格遗物旧卡仍固定 80。
- 新回血卡为 `reward:heal:<amount>`，恢复按已经显示的数额兑现。旧 `reward:heal` 继续使用旧公式 `round(12 + enMax × 0.12)`，不会把尚未领取的旧卡改成新小额卡。
- 价格与新版治疗额必须是正安全整数；未知商品或异常 id 不生成可执行动作。展示文本沿用原有转义边界。
