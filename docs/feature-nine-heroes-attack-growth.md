# 九角色与累计攻击成长（2026-10-04）

九个角色共用既有战斗输入与完整词致命伤害规则。进攻收益换取生命/提示代价；未增加道具、地图系统或成长币种。

| 角色 | 本体生命 / 提示 | 主要个性 |
|---|---|---|
| 学者 | 60 / 4 | 一次提示揭示 2 字母，无错误、无帮助整词大招 +15% |
| 战士 | 85 / 2 | 整词 +2 盾，每战最多 6；有盾整词大招 +20% |
| 探险家 | 65 / 3 | 少 2 干扰字母，每战首词大招 +50% |
| 幸运儿 | 65 / 3 | +15 初始金币，收益 +20%；每携带 50 金币大招 +5%，最多 +20% |
| 治愈师 | 65 / 3 | 每战开场回 10，溢出转最多 4 盾 |
| 游侠 | 50 / 3 | 合格新字母回 1，每战最多 18；主动帮助或出错停止本词回血 |
| 狂战士 | 60 / 2 | 整词大招 +25%；生命不高于一半提高至 +45% |
| 焰术师 | 55 / 2 | 至少 7 个字母的大招 +40% |
| 影刃 | 55 / 2 | 无错误、无帮助大招 +35%；敌生命不高于 35% 提高至 +60% |

无帮助要求 wordQ 中 wrong/hint/listen/revealed 均为 0，缺失/坏记录不伪称完美。条件大招百分比为替换档位，不重复累乘。影刃按字母攻击之后的敌血计算收割，战士/狂战士按连击资源发放后的状态计算；卡片预估逐字模拟同一顺序并克隆里程碑账本，不能提前发奖励。

知识成长只认正式默写的教材词去重交集，每 10 词攻击 +4%，150 词封顶 +60%；原每 20 词生命 +1、最多 +12 保留。攻击与装备增伤相加后再参与现有连击、怒火、怪种和角色倍率，最终受既有字母/大招上限约束。半词不能击杀或记学会，跳过/逃跑没有击杀收益。新轮冻结版本 2 事实，暂停、刷新、跨单元不重算。旧版本 1 仍只加生命，未知字段与存档 key 不变。

角色卡/装备详情显示加成及代价，主页显示下轮成长。新角色有斧头、火杖尖帽和面罩匕首；旧六位的脸部、部件与外观保持，新增 hero-roster.css 在七张冻结表之后加载。未改词库。
