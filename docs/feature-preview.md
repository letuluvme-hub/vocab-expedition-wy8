# 单词预习（2026-10，替代每日默写）

站长反馈：每日默写要用完整键盘手动输入，太不实用。改成轻量的预习：简单过一遍词库，提示不限次数，单元随便选。

## 流程

1. 主页底部「练习与收藏」→「开始预习」。
2. 选教材册（八上 / 八下）和单元。所有单元都开放，不看远征解锁；也可以展开「用自己的词表预习」粘贴词表。
3. 整个单元按课本顺序一次过完（上限 60 词，最大的教材单元 55 词；自定义词表超过 60 词时下次接着往后）。
4. 每个词：看中文，从字母盘选字母拼英文（电脑上可以直接打字）。
   - 「提示一个字母」不限次数，直接替你填上下一个字母（F2）。
   - 「跳过这个词」随时可用（F8）。
   - 拼完点「下一个」（Enter）。
5. 过完最后一个词就是「预习完成」：拼完几个、不看提示拼对几个、跳过几个、用时。
6. 不限时；可以暂停、回主页、刷新，回来接着练。

## 记什么

| 情况 | 记录 |
| --- | --- |
| 不看提示拼完 | 写进 `mastered`（学会），会话的 `cleanDone` |
| 用了提示拼完 | 只记练过；当天日报「错词／辅助词」里列出这个词 |
| 跳过 | 会话的 `skipped`，不记学会也不记错 |
| 任何情况 | 不写 `dictationMastered`、`reviewQueue`，不做正式评估 |

打卡、今日外观、练习时长、练习词数照旧。家长日报里没有正式默写记录时不再显示「一次拼对率」。

## 「学会」统一口径

`learnedWords = dictationMastered ∪ mastered`（trim + 小写去重，只数教材词的地方照旧只数教材词）。读它的地方：

- 单元解锁（`runtime.campaignState`）
- 新开远征的生命 / 攻击成长（`growthFact`、`growthSummary`）
- 墨芽成长阶段与词卡「学会了」（`domain/daily-collection.js`）
- 主页「学会单词」统计与单元卡「学会 N/M」（`ui/screens/title.js`）

成长事实在开局时冻结，已在进行中的远征不受影响；新开一轮才按新口径计算。

## 兼容

- 会话多了可选字段 `mode: 'preview'`、`cleanDone`、`skipped`；`schemaVersion` 仍为 1，存档 key 不变。
- 旧版每日默写会话（没有 `mode`）照旧恢复，继续走「热身 → 正式默写」直到结束。`controller.start({ mode: 'dictation' })` 仍能开旧版会话，只供回归测试使用，界面上不再提供入口。
- 发布验收（`scripts/verify-public-checks.mjs`、`tests/release/smoke.spec.js`）改为走预习流程。
