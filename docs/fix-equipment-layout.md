# 装备清单说明错列修复

截图里的遗物说明被挤入左侧窄列，是因为原两列网格依次放入图标、标题、说明三个直接子元素。第三个元素被自动放进下一行的第一列。

图标现在放在标题内部，每行仍只有“图标和名称 / 效果说明”两个网格单元。正文继续使用 textContent，图标只来自既有固定像素素材。面板不修改任何装备、战斗或存档状态。角色与当前护盾等无图标行沿用原布局。

改动文件：`src/ui/components/equipment-panel.js`、`src/styles/equipment-panel.css`、`tests/e2e/equipment-panel.spec.js` 及本文。未触碰七张冻结样式表。

先补充 320 / 390 / 1024px 浏览器测试：旧实现三个视口全部因说明落入左列失败；修复后整个面板规格 16 通过。测试检查说明在名称右侧、与名称顶端对齐、占据一半以上宽度、图标不跨列，保留原有点击、窄屏溢出、暂停恢复和不修改状态的断言。把图标重新放回外层的变异使三个新测试全部失败（退出 1），随后恢复修复。

完整门禁与部署结果记录在本修复 PR。测试覆盖桌面及 Chromium 模拟手机尺寸，尚未进行 iOS/安卓真机验证。
