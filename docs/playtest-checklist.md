# 实机观察清单 · integration/opt-all

> 四个优化分支交叉合并后的验证清单。**这些数值全部来自纸面推演和自动化测试，没有一条经过人玩。**
> 这一步只能由你做。每条都写了「怎么测」和「什么算问题」，不需要你判断数值对不对，只需要判断**手感**。

## 怎么开始

```sh
npm run dev
```

打开终端给出的地址（形如 `http://127.0.0.1:5174/vocab-expedition-wy8/`）。

⚠️ **这个分支和线上不是一回事。** 改动全在 `integration/opt-all`，`main` 仍是原版。
想对比请另开一个终端跑 `git checkout main && npm run dev`。

**测之前建议**：进新远征前先在主页把「声音控制」调好，避免战斗中语音干扰判断。

## 一、难度收敛（分支 1，最需要你判断的一条）

### 背景

整词伤害的上限原本是一个与深度无关的常数 `560`。floor 40 之后玩家输出被钉死而敌人血量继续涨，
「打空一个敌人需要的词数」从 floor 1 的 3.4 一路涨到 floor 400 的 31.7 —— 越玩越累。
现在上限随楼层等比增长，这条曲线收敛到 **~3.8 词（保守构筑）/ ~2.3 词（拿到连击徽章）**。

### 怎么测

打到 **floor 20 以上**（跨单元继续），留意每场战斗**打几个词**。

| 观察点 | 什么算问题 |
|---|---|
| floor 1-9 的手感 | 如果和原版**不一样**，是 bug —— 浅层设计成逐位不变 |
| floor 20-40 | 战斗节奏是否还紧凑？会不会 2 个词就秒，感觉不到压力？ |
| floor 40+ | 是否仍单调变累？收敛应该止住恶化，但不该变简单 |
| 深层单场时长 | 原来深层一场要打 8-30 个词，现在 3-4 个。**会不会太短、太没仪式感？** |

### 我的不确定性

- 收敛值 3.8 **不是**我原本建议的 2-3。因为不能动敌人血量（那是清单 10 的范围），
  而 floor 1 的 3.38 词不允许改 —— 深层收敛到 2 词就变成「深层比浅层容易」。
- 所以深层比前期**略难一点**，这是有意的。如果你觉得这个递增感别扭，告诉我。

## 二、怪物分层（分支 2）

### 背景

`enemies.js` 里 8 种怪各有一个 `base` 字段，但**此前是全项目零引用的死数据** ——
8 种怪在规则上完全等价，只是换了张脸。现在 `base` 真正接进血量，倍率锚在 8 怪均值上：

| base | 倍率 | 怪物 |
|---|---|---|
| 3 | ×0.65 | 词灵 |
| 4 | ×0.85 | 语素蛛、拼写幽灵 |
| 5 | ×1.05 | 石化词素、歧义章鱼、单复数蝎 |
| 6 | ×1.25 | 冰封词灵、词形旋风 |

**8 选 1 等概率时，期望血量和改动前逐点相同** —— 移动的是方差，不是难度。

另外给**石化词素**做了一个示范机制：单字母伤害 ×0.75、整词大招 ×1.5。

### 怎么测

刻意注意**同一层里抽到不同怪**时的感受差异。

| 观察点 | 什么算问题 |
|---|---|
| 词灵（×0.65） | 是否明显感觉"这只好打"？应该一眼可辨但不至于太弱 |
| 冰封词灵/词形旋风（×1.25） | 是否明显感觉"这只硬"？ |
| **石化词素** | 机制的核心检验：磨字母是否真的变慢？打整词是否明显更疼？**你有没有因此改变打法？** |
| 精英与首领 | 抽到精英时倍率恒为 1（不叠怪种），是否反而比某些普通怪软？ |

### 我的不确定性

- **±25% 的血量差异，从 3.4 词变成 2.6 或 5.0 词** —— 纸面上"词灵 2.6 词"可能短到机制来不及展开。
- 石化词素的 0.75/1.5 是否让人真的想"换打法"，我完全没验证过。
- **击杀回血是 `12 + enMax×0.12`**，所以打词灵回血少、打冰封回血多。这是分层带来的真实副作用，
  我不知道是否可接受。

## 三、战意·连击里程碑（分支 3）

### 背景

新增第二条成长线：连击 6 → 护盾+8，连击 10 → 生命+8，连击 12 → 提示+1，**一轮各一次**。

和已有的「知识成长」（掌握词汇换下轮生命上限）并存 —— 后者答"你学了多少"，这条答"你打得多准"。

### 怎么测

连续答对字母时留意战斗页新出现的「战意」提示。

| 观察点 | 什么算问题 |
|---|---|
| 触发频率 | 门槛定在 6/10/12（不是我原本建议的 10/25/50）。**6 连击是不是太容易碰到？一局会不会发完三次就没了？** |
| 奖励价值 | +8 护盾/生命/+1 提示，够不够有感？ |
| 和连击伤害的关系 | 连击每 5 已经加一次伤害加成，这三条会不会让连击流过强？ |
| 战意条显示 | 战斗页新增约 14px 高度。**手机（尤其 320px 宽）上有没有把字母盘挤出屏幕？** |

### 我的不确定性

- **门槛可能是错的。** 我原本建议 25/50，但 agent 发现 `combat.js` 里连击在整词完成时就清零了，
  上限就是单词字母数 —— 259 词里 ≥12 字母的只有 12 个词，25/50 永远触发不了。
  它按实际字母数重定了 6/10/12。但**6 是否太松，只能你判断**。
- 移动端布局完全没验证过。

## 四、装备深度（分支 4）

### 背景

稀有度分级：普通 60 / 稀有 110 / 传说 175 金（单次抽取约 1.3% 出传说）。
4 组组合技（两件遗物凑齐才生效）+ 1 件传说遗物「预知残卷」。

| 组合 | 效果 |
|---|---|
| 荆棘壁垒 | 护盾符文 + 荆棘护符 → 反弹 5→8，其中 4 点转护盾 |
| 连击共鸣 | 连击徽章 + 专注头环 → 保留的连击每点换 3% 本场增伤 |
| 铁血循环 | 永动电池 + 锻造台 → 每层额外回 6、每场胜利额外回 4 |
| 点金术 | 聚宝盆 + 学者之书 → 胜利金币 25→45，先知卡必掉 |

### 怎么测

重点是**攒金币和做选择的过程**，不是拿到的瞬间。

| 观察点 | 什么算问题 |
|---|---|
| 商店价格 | 110/175 金贵不贵？和敌人掉的金币比 economy 是否失衡？ |
| 传说概率 | 1.3% 是"稀有但不憋屈"还是"一整轮见不到一次"？ |
| 组合技可发现性 | 你凑齐两件之后，**有没有意识到它们互动了**？面板上能看到吗？ |
| 荆棘壁垒强度 | 「荆棘壁垒在护盾流里可能滚雪球」—— agent 自己标的怀疑，重点看 |
| 道具变化 | 透视之眼原本"不消耗提示次数"（永远优于按提示键），现在消耗 1 点额度。有没有影响使用节奏？ |

### 我的不确定性

- 经济系统完全没跑过模拟。60/110/175 是否和逐层金币曲线对齐，只有玩才知道。
- 营火冥想也吃传说权重，没有做"营火不出传说"的特殊处理。

## 五、跨分支的已知隐患

这几条是合并过程中实测到的，**不是我的猜测**：

### ⚠️ 深层怪种机制失效（清单 10）

`hitDmg` 的单字母上限 `140` 是深度无关的常数，而怪种机制倍率也乘在上面。
实测 **floor 200 起，石化词素的 ×0.75 字母惩罚被完全吃掉**（plain 140、stone 140，
而 plain×0.75 应为 105）—— 一个双向权衡退化成"只白给 +50% 大招奖励"。

**如果你打到 floor 200+，请专门留意石化词素是不是"手感变轻了"。**
（地图 `MAP_ROWS = 9`，正常流程打不到 200 层，所以这条大概率碰不到。）

### ⚠️ 首领可能不是最强的

BOSS 血量按写死的"第 9 层"口径算。第 9 层最强普通怪（冰封词灵 ×1.25）已经 960，
首领 1000 —— **只差 40 血**。当前地图 9 行时不致命，但扩到 15 层以上精英会超过首领。

**如果你觉得首领战"不够硬"，很可能是这个原因，而不是数值配错了。**

### ⚠️ 里程碑刷取漏洞（正在修）

连击里程碑记在 `run.milestones`，而该字段此前不进存档 —— "暂停 → 刷新 → 继续"会重置，
玩家可以反复刷提示次数（护盾/生命被上限夹住无害，提示次数是无限的）。
**正在修**，修完后请专门测一次：触发里程碑 → 暂停 → 刷新 → 继续，看是否重复发放。

## 六、怎么记录

最省事的办法是边玩边说，我来整理。比如：

> "打到第 5 层，一只词灵，3 个词就打死了，感觉有点快"
> "攒了 200 金买不起传说，是不是太贵了"
> "凑齐了护盾符文和荆棘护符，但我不记得它们有联动"

也可以只回答最关心的：**一和二优先**（难度和怪物是这次改动最大的部分），
三四可以等合并后慢慢看。
