# 角色解锁与开荒学者

角色能力保持原有定位，解锁条件按入门、熟练和高风险操作逐步提高。同一角色卡的多项条件必须全部完成。学者是初始角色，避免首次打开无法开始。

| 角色 | 解锁条件 |
| --- | --- |
| 学者 | 初始开放 |
| 探险家 | 完整拼词 12 次 |
| 战士 | 击败怪物 5 只 |
| 幸运儿 | 完整拼词 30 次 |
| 治愈师 | 实际回血 60 点 |
| 游侠 | 完整拼词 60 次，实际回血 120 点 |
| 狂战士 | 实际伤害 4,000 点，击败怪物 15 只 |
| 焰术师 | 完整拼词 100 次，实际伤害 6,000 点 |
| 影刃 | 无错、无提示、无听音、无揭示拼词 80 次，击败怪物 30 只 |

学者新远征生命上限由 60 改为 80，每场基础提示由 4 改为 5；主动提示仍揭示 2 个字母。移除无帮助整词 +15% 的角色加成，让提示和角色定位一致。拼写质量的通用伤害判档与正式掌握标准不变。现有远征恢复使用其保存的生命、提示等事实，不重新发放开局属性。

统计保存在同一个 `wy8a_rogue_v1` 存档的 `heroStats`：words、cleanWords、kills、damage、healing。词在整词完成时累计，半词、撤退、延后不累计。每日只统计正式完整结果，不重复统计热身；符合正式独立回忆标准的结果累计 cleanWords。战斗、奖励、商店、事件和营火只累计实际恢复的生命，满血、护盾、生命上限成长不计回血。伤害按敌人实际失去的生命累计，最后一击超过剩余生命的部分不计。击杀复用真实胜利的幂等入口，不改变远征次数或通关记录。

旧存档只把原有 `mastered` 中去重的完整词记录作为初始 words；无明细的旧伤害、击杀、回血和无帮助次数从 0 开始，不推测补账。未知字段、当前远征和学习记录保留。锁定的已选角色在新远征回退到学者；正在继续的旧远征角色不变。清空进度会同时清空解锁统计。

主页显示条件及当前/目标，锁定卡不响应选择；应用层同样检查选择条件，新局获取角色时再次回退，避免单靠 disabled 挡输入。角色图像和数值规则由既有模块提供。浏览器回归使用已满足角色前提的测试存档来验证旧角色技能；新解锁用例明确从全零统计开始，通过真实整词、击杀、道具、暂停、刷新和每日流程验证累计。
