# 商店数量与实时文案修复 · 2026-10-04

审计八种道具的现价与旧价、连续购买、库存超单场使用上限、金币不足及暂停恢复。每次实际购买均为三件，现价写在稳定选项 id 中，跨版本恢复仍按原卡价格成交；没有发现少发道具。确认显示缺陷：磨砺石购买后限购余量不更新，恢复后也会显示旧余量；药剂只缺五生命却仍写回复三十五。卷轴与道具缺少实时库存，容易把每场额度理解为购买数量。
