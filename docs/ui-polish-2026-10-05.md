# UI 检查后的统一修整

接着战斗页那一轮（`docs/battle-card-fill-2026-10-05.md`），把 UI 检查清单里剩下几项一起改掉。
样式集中在新增的 `src/styles/ui-polish.css`，由 runtime 引入，排在所有样式之后；冻结的七张样式表没动。

## 主页

- 单元卡在 480 宽以下由三列改两列。三列时「Unit 3 成长与发现」「Unit 4 记忆与学习」这类标题会折行
- 角色卡的属性说明和解锁进度原来是 9.5px 和 10px，统一提到 11px
- 「知识成长」里两行攻击说明没设字号，掉回浏览器默认的 16px，比标题还大。收回到 13px 和 12px
- 统计五项原来排成「4 + 1」，「最深层」单独掉一行。现在一行五列

## 商店、营火、战斗奖励

- 遗物和道具的像素图标原来被 `.pick span {display:block}` 挤到标题上方单独占一行，改为和标题同行，和 emoji 图标对齐
- 现在买不了或用不上的商品显示为灰色：满血时的疗伤药剂、提示卷轴已买满、遗物已集齐时的宝箱。
  卡片仍然可以点，点了只给说明、不扣款，购买逻辑没改（`src/app/encounters.js` 只多了一个外观标记）

## 地图

「暂停并保存 / 放弃远征」改为钉在视口底部（sticky）。电脑 1280×800 下原来要滚到地图最底下才看得到。

## 暂停页

底部那句「离开这一页前进度已经存好」删掉了。它和上面的状态文字重复，而且在没存上的情况下也会照样显示。
状态文字本身由 `pause.js` 按真实保存结果给出，没存上时不会说已保存（单测有覆盖）。

## 验证

- 新增 `tests/e2e/ui-polish.spec.js` 4 条：单元两列、统计一行、成长区字号不超过 13px、角色卡说明不小于 11px、
  商店图标和标题同行、满血时药剂灰显且其他商品不被误灰、地图按钮在 1280×800 首屏内、暂停页不再重复说已保存。
  改动前的代码 4 条全部失败
