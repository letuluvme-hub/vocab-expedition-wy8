# 电脑键盘快捷键

常用按键直接触发当前屏幕上对应的按钮，仍走原来的费用、学习记录与存档路径。键位标记只在宽度至少 768px、支持悬停的精细指针设备上显示；手机保留触摸按钮并隐藏键位。普通拼写仍使用 A–Z，退格撤销。

| 场景 | 键位 | 操作 |
| --- | --- | --- |
| 主页 | Enter / F2 | 继续或开始远征 / 每日默写 |
| 地图 | 1–9 / Esc | 选择可走节点 / 暂停 |
| 战斗 | Shift+1/2/3 | 选择左、中、右词卡 |
| 战斗 | Tab / Shift+Tab | 向后 / 向前切换词卡，动笔后锁定 |
| 战斗 | 1–9 | 使用对应道具 |
| 战斗 | F2 / F3 | 提示 / 听音 |
| 战斗 | F8 / F9 / Esc | 跳过 / 撤退 / 暂停 |
| 暂停 | Enter 或 Esc / F4 | 继续 / 返回主页 |
| 奖励、事件、营火、商店 | 1–9 | 选择对应选项 |
| 奖励 / 商店 | F8 / Esc | 跳过奖励 / 离开商店 |
| 每日默写 | Enter / Esc | 当前主要操作 / 暂停或恢复 |
| 每日默写 | F2 / F8 / Backspace | 提示 / 留待复习 / 撤销 |
| 结算、学习完成 | Enter / Esc | 继续下一步 / 返回主页 |
| 图鉴、导入页 | Esc | 返回主页 |

输入框、文本框、下拉框及可编辑内容不被全局快捷键接管。Ctrl、Alt、Command、输入法组合输入不触发游戏命令；长按产生的重复快捷键不连续消费道具或提示。聚焦按钮时 Enter 保留浏览器原生操作。

实现范围：`src/ui/keyboard-shortcuts.js` 负责当前屏幕可见按钮映射与键位标记；`runtime.js` 接入输入路由；新增独立作用域样式 `keyboard-shortcuts.css`；`word-offer.js` 移除手机常驻电脑说明。七张冻结 CSS 和掌握判定不变。

先新增 4 个真实浏览器失败测试，再实现快捷键。补充完成页出口及地图标签回归，均先失败再修复。键位使用独立的 kbd 元素，避免占用地图既有的伪元素类型标签。删除 Ctrl 保护的关键变异使单测失败（退出 1），之后恢复。

测试文件：`tests/unit/keyboard-shortcuts.test.js`、`tests/e2e/desktop-shortcuts.spec.js`；新增样式分别登记在 styles 与 extraction 测试，保留原冻结样式的逐字节对照。完整门禁与部署结果记录在本功能 PR。尚未进行 iOS/安卓真机验证。
