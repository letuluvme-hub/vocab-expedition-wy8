# 致死跳过确认

普通跳过扣除 50 点生命。当前生命不高于 50 时，按钮和 F8 都先弹浏览器确认，明确显示当前生命与远征立即结束的结果。取消不扣生命、不推进节点、不改存档；确认只结算一次战败，不领取怪物奖励。有护盾也不能抵扣跳过的生命成本。影分身本轮首次免费撤退与可承受的普通跳过直接执行。

确认端口属于 runtime 浏览器能力接线，combat 负责判定与结算。确认能力缺失时拒绝致死跳过；确认后重查战斗身份及结束状态。存档 key、词库、伤害规则与七张冻结样式表未改。
