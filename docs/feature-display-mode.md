# 平板显示方式

平板主页「开始游戏」和新手引导下面有一排「显示方式」按钮，有自动、手机版式、电脑版式三档。手机和电脑上不出现。

## 为什么要有

全站版式靠宽度断点切换：640 以下是手机单列，900 以上是电脑左右分栏。平板正好卡在中间。
竖屏 iPad Pro 宽 1024，会套电脑分栏，题目卡和字母盘挤在上半屏，下半屏空着；
820 宽的平板走单列，但字母键还是手机尺寸，显得小。孩子用平板时，家长可以按手感自己选。

## 怎么实现

不另写一套 CSS，只改 `<meta name="viewport">` 的 width，让浏览器按指定宽度排版、再等比铺满屏幕。

| 方式 | 竖屏 | 横屏 |
|---|---|---|
| 自动 | device-width（原样） | device-width（原样） |
| 手机版式 | 480 宽，手机单列放大 | 640 宽，手机横握的左右分栏 |
| 电脑版式 | 1024 宽，电脑分栏 | 设备宽度不足 1024 才改成 1024 |

横屏的手机版式不用更宽的值。640–900 之间、高度又在 480 以上的那一档，战斗页的题目卡会被字母盘和双方战况挤成几十像素高（这是原有问题，见下）。

转屏时监听 `(orientation: landscape)`，手机版式在 480 和 640 之间换。meta 内容没变就不写，避免 resize 循环。

## 谁能看到

触屏设备且屏幕短边 ≥ 600 CSS 像素才算平板。iPadOS Safari 报桌面 UA、接触控板还会命中 `pointer:fine`，所以「Macintosh + maxTouchPoints > 1」也算平板。电脑浏览器忽略 meta viewport，给了选项也不起作用，所以不给。

## 存在哪

本机 `localStorage` 的 `wy8a_display_v1`，值是 `phone` 或 `desktop`；选回自动就删掉这个键。不进 `wy8a_rogue_v1` 学习存档，清档不影响它，读写失败一律按自动处理。非平板设备上即使存了值也不生效。

## 已知遗留

不改 viewport 时，宽 640–900、高 481–700 左右的窗口（小窗口电脑浏览器、部分安卓平板横屏）战斗页题目卡会被压到几十像素，要在 `.fmid` 里滚动才看得到。这次没有动战斗页的断点，平板用户可以切到手机版式绕开。

## 验证

- `tests/unit/display-mode.test.js`：宽度规则、平板判定、偏好存取、转屏、组件契约
- `tests/e2e/display-mode.spec.js`：820×1180 平板模拟下三档切换后 `innerWidth` 真的变成 480 / 1024 / 820，刷新后保留，手机版式战斗页是单列且题目卡在字母盘上方；手机上不出现
- 未验证：iPad Safari 与安卓平板真机上改 meta viewport 后的缩放表现（Chromium 模拟与真机可能有差异）
